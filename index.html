Masukkan Web App URL dari Google Apps Script yang sudah Anda deploy sebagai Anyone (Siapa saja):

💡 Cara Dapatkan URL:

1. Buka Spreadsheet > Extensions > Apps Script

2. Paste kode dari file google-apps-script/Code.gs

3. Klik Deploy > New deployment > Web app

4. Set Who has access ke Anyone, lalu salin URL yang berakhiran /exec
